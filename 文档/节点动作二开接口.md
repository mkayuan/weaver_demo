
# 节点动作二开接口配置说明

### 一 、 基本信息

##### 1. 功能描述

 - 使用建模表实现流程节点动作调用简单Restful API 可配置化

##### 2. 相关文件


| 文件地址                                        |              描述               | 
|:--------------------------------------------|:-----------------------------:|
| /ecology/classbean/SecondDev/action/ActionSecondApi.class |            节点动作类文件            | 
| /ecology/classbean/SecondDev/action/RequestBodySecondUtil.class |           配置信息工具类文件           | 
| 建模配置表代码块.html                                   |           请求报文测试功能            | 
| /ecology/SecondDev/service/ActionSecondApi.jsp |           请求报文测试功能            | 
| 模块-节点动作二开接口.zip | 配置表建模模块，表名 uf_ActionSecondApi | 


### 二 、 配置节点动作


> 节点动作类文件
> > SecondDev.action.ActionSecondApi

> 参数
> > xzjk  对应建模表选择接口下拉框字段id


### 三 、 建模表配置接口信息


***建模表表名 uf_ActionSecondApi***

 - 主表
 

|  字段名   | 数据库字段名 |  字段类型  | 字段说明                                          |
|:------:|:------:|:------:|:----------------------------------------------|
|  选择接口  |  xzjk  |  下拉框   | 选择执行接口                                        |
|  流程id  |  lcid  |   数字   | 流程workflowid                                  |
|  接口地址  |  url   |   文本   |                                               |
|  返回字段  |  fhzd  |   文本   | 用于判断接口响应是否成功字段 </br> 只能在json结构第一层 </br> 没有则不填 |
|  成功标识  |  cgbs  |   文本   | 接口响应成功字段值                                     |
| 测试流程id |  csid  |   数字   | 测试requestid                                   |
| 取消日志输出 |  log   | Check框 | 0默认输出日志，1选中不输出日志                              |
| 测试报文 |  	csbw   |   文本   | 显示模板转换为按钮，根据测试流程id生成测试报文                      |


- 明细一

|   字段名  | 数据库字段名 | 字段类型  |     字段说明     |
|:---:|:------:|:----:|:------------:|
|   header参数名  |    headername    |  文本  |        |
|  header参数值   |    headervalue    |  文本  | 需要加密则维护加密后的值 |


- 明细二

|   字段名  | 数据库字段名 | 字段类型  | 字段说明                                                                   |
|:---:|:------:|:----:|:-----------------------------------------------------------------------|
|   接口字段名  |   jkzdm     |  文本  |                                                                        |
|  流程字段名   |    lczdm    |  文本  |                                                                        |
|  父节点   |    fjd    |  文本   | 该接口字段的父节点名                                                             |
|   明细号  |     mxh   |  数字   | 流程字段所属明细号，主表为0                                                         |
|   是否数组  |   isarray     |  Check框   | 接口字段对应值是否为数组                                                           |
|   固定值  |    gdz    |  文本   |                                                                        |
|   特殊字段  |    tszd    |  下拉框   | 0：时间戳 <br/>   1：布尔类型  字段值=1传false，0或空传true  <br/> 2: 集合 将字段按英文逗号分隔组成集合 |


### 四 、 请求报文测试功能

 1.模块显示模板添加代码块 建模配置表代码块.html

 2.显示模板测试报文字段转换为按钮，根据测试流程id生成测试报文
